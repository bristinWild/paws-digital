# PAWS — Wild Ventures (host pack)

A self-contained, pre-built browser playtest package: Learn to play, solo
vs. Naledi, play with bots, and room-code multiplayer for friends.

- **Hosting it:** see [HOSTING.md](HOSTING.md) — requirements, run locally,
  run on a VPS/Render/Fly/Railway-style host, reverse proxy notes, where
  room saves go, restart behaviour, and a safety note.
- **Playing it:** see [PLAYTEST.md](PLAYTEST.md) — how to start each mode
  and how to join a room with a code.

Quick start: `node server.mjs` (requires Node.js 22+), then open the URL it
prints.
